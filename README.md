# Marmara Yemek Group

Marmara Yemek Group için Türkçe, duyarlı kurumsal tanıtım sitesi. Toplu yemek, restoran ve yazılım çözümleri tek bir landing page üzerinde sunulur.

## Başlatma

Proje statik HTML, CSS ve JavaScript kullanır; paket kurulumu gerekmez. `index.html` dosyasını tarayıcıda açabilir veya VS Code içindeki herhangi bir statik sunucu eklentisiyle görüntüleyebilirsiniz.

## İçerik

- `logo.pdf` dosyası üst ve alt bölümde marka logosu olarak kullanılır.
- Kurumsal tanıtım ve hizmet alanları
- Mobil uyumlu gezinme menüsü
- Yaklaşım ve iletişim bölümleri
- Toplu yemek ön görüşme formu WhatsApp’a yönlendirme, telefonla arama
- Restoran için tarih/saat/kişi sayılı WhatsApp rezervasyon talebi
- Yazılım çözümleri için ayrı WhatsApp iletişim hattı
- Yazılım çözümleri bölümünde örnek çalışmalar: akyalitim.com ve örnekisdekor.com
- Genel iletişim formunda seçilen hizmete göre WhatsApp yönlendirmesi

- Toplu yemek iletişim hattı: 0 546 905 55 27 (telefon ve WhatsApp).
- Yazılım çözümleri WhatsApp hattı: 0 531 244 57 05.
